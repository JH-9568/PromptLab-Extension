ChatGPT, Gemini, Claude에서 더 좋은 AI 답변을 받을 수 있도록 프롬프트를 개선합니다.

PromptLab은 사용자가 작성한 간단하거나 모호한 프롬프트를 더 명확하고 실행 가능한 요청으로 바꾸고, 개선본을 AI 입력창에 바로 적용하는 Chrome 확장 프로그램입니다. 원래 의도는 유지하면서 목적, 맥락, 출력 형식과 제약 조건을 더 분명하게 정리합니다.

사용 방법

1. ChatGPT, Gemini 또는 Claude를 엽니다.
2. AI 입력창에 프롬프트를 작성합니다.
3. PromptLab을 실행합니다.
   - Mac: Command+Shift+;
   - Windows/Linux: Ctrl+Shift+.
4. 입력창에 바로 적용된 개선본을 확인합니다.
5. 필요하면 되돌리기를 눌러 원본 프롬프트를 복원합니다.

입력창 테두리 색상 변경

1. Chrome 툴바에서 PromptLab 아이콘을 누릅니다.
2. 입력창 테두리 색상에서 10개 색상 중 하나를 선택합니다.
3. AI 탭으로 돌아가면 선택한 색상이 자동으로 적용됩니다.

주요 기능

- ChatGPT, Gemini, Claude 입력창에서 바로 동작
- 별도 편집 화면 없이 단축키로 프롬프트 개선
- 원래 요청의 의도를 유지하면서 명확성과 구조 개선
- 개선본을 AI 입력창에 자동 적용
- 한 번의 되돌리기로 원본 프롬프트 복원
- 입력창 테두리 색상 10종 제공
- 한국어 및 영어 인터페이스 지원
- 긴 프롬프트와 첨부 파일이 있는 입력창에도 반응형 테두리 적용

개인정보 처리

개선본 생성을 위해 프롬프트 텍스트가 PromptLab 백엔드로 전송되며 OpenAI API에서 처리될 수 있습니다. PromptLab 분석 로그에는 원본 및 개선 프롬프트 전문을 저장하지 않습니다. 익명 사용자 ID, 세션 ID, 대상 AI 플랫폼, 개선 메타데이터, 프롬프트 해시와 글자 수 등 제한적인 익명 메타데이터만 저장합니다.

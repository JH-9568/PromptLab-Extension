더 명확한 프롬프트, 단축키 한 번으로.

PromptLab은 ChatGPT, Gemini, Claude 입력창에서 프롬프트를 다듬는 Chrome 확장 프로그램입니다. 별도 편집 화면을 열지 않고, 원래 의도를 유지하면서 더 명확한 요청으로 바꿉니다. 개선본은 입력창에 바로 적용되며 필요할 때 원본으로 되돌릴 수 있습니다.

사용 방법
1. 지원하는 AI 사이트에서 프롬프트를 작성합니다.
2. Mac에서는 Command+Shift+;, Windows/Linux에서는 Ctrl+Shift+.를 누릅니다.
3. 입력창의 개선본을 확인하고, 원본이 필요하면 되돌리기를 누릅니다.

원하는 만큼만 개선
Chrome 툴바에서 PromptLab 아이콘을 누르면 개선 강도를 선택할 수 있습니다.
- 가볍게: 표현과 명확성을 중심으로 다듬습니다.
- 균형: 필요한 답변 조건을 보완합니다. 기본 설정입니다.
- 자세히: 관련된 구조, 기준, 실행 단계를 구체화합니다.

내 기본 조건 저장
코드에 사용할 언어, 답변 형식, 말투 등 자주 쓰는 조건을 최대 600자까지 저장하세요. 저장하면 적용 스위치가 켜지고 다음 개선부터 반영됩니다. 스위치를 꺼도 내용은 유지되며, 내용을 지우고 저장하면 삭제됩니다. 원문에 명시한 조건이 저장 조건보다 우선합니다.

테두리 색상 변경
Chrome 툴바 → PromptLab → 입력창 테두리 색상에서 10가지 색상 중 하나를 선택하세요. 열려 있는 AI 입력창에 자동 적용됩니다.

주요 기능
- ChatGPT, Gemini, Claude 입력창에서 바로 개선
- 단축키 실행 및 개선본 자동 입력
- 원본으로 되돌리기
- 개선 강도 3단계와 내 기본 조건
- 입력창 테두리 색상 10종
- 한국어·영어 UI와 밝은·어두운 설정 화면
- 긴 프롬프트 및 첨부 파일에 맞춰지는 테두리

개인정보
프롬프트 텍스트는 개선을 위해 PromptLab 백엔드 및 OpenAI API로 전송됩니다. 저장 조건은 현재 브라우저에 보관되며 적용 스위치가 켜졌을 때 함께 전송됩니다. 분석 로그에는 원본·개선 프롬프트 전문이나 저장 조건 전문을 별도 필드로 저장하지 않습니다. 익명 사용자·세션 ID, 대상 플랫폼, 개선 메타데이터, 프롬프트 해시와 길이 등 제한적인 메타데이터를 저장합니다.
